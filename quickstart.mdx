## Two ways to use it

### 1. Hosted link

Akapulu Labs hosts a public page for you. You pick an avatar, write what the conversation is for, and get a URL. Anyone with the link opens it and clicks **Start Call**. You do not run a bot, and that page never sees your API key.

Best when you want a working call quickly, or something you can share.

### 2. Your own avatar chat

You run a **voice pipeline**. That can be speech-to-speech, STT → model → TTS, or anything else that produces assistant audio. Akapulu Labs adds the **avatar video** on top.

You create the WebRTC room: [Daily](https://www.daily.co/) with [Pipecat](/guides/calls/pipecat), or [LiveKit](https://livekit.io/) with [LiveKit Agents](/guides/calls/livekit). Three participants join it:

- The **browser** is the person on the call.
- The **voice bot** is your pipeline. It listens and does not publish the face.
- The **Akapulu Labs worker** publishes the face and the played audio.

On Pipecat, [`AkapuluAvatar`](https://github.com/Akapulu/pipecat-akapulu) sits inside the voice bot after assistant audio. On LiveKit Agents, [`AvatarSession`](https://github.com/Akapulu/livekit-akapulu) does that job. Neither plugin is the worker itself.

Best when the avatar should live in your product or next to your own bot.

## Get started

1. [Sign up or sign in]({{app-url}}/).
2. Pick a path below.

### Path A: Hosted link

In the dashboard, create a [hosted link](/guides/calls/hosted-links). Pick an avatar, write the system prompt, and choose whether to show **This is AI**. Save, open the URL, and click **Start Call**.

You can also create the same row with an API key via [`POST /api/hosted-links/`](/api-reference/hosted-links/create).

### Path B: Your own voice bot

1. Create an [API key]({{app-url}}/settings/api-keys/).
2. Pick a stack:
   - **Pipecat / Daily** — create a Daily API key. Run the public [example](/examples), or call `create_akapulu_call` and add `AkapuluAvatar`. Guide: [Pipecat](/guides/calls/pipecat).
   - **LiveKit Agents** — set `LIVEKIT_URL`, `LIVEKIT_API_KEY`, and `LIVEKIT_API_SECRET`. Use `create_akapulu_livekit_call` or `AvatarSession.start`. Guide: [LiveKit](/guides/calls/livekit).

See [How it works](/guides/getting-started/how-akapulu-works) for how the room and live session fit together.
