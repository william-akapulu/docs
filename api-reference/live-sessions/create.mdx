---
title: "Create a live session"
description: "Start the avatar in a Daily room you already created."
---

`POST /api/live-sessions/`

You create the Daily room and the avatar's meeting token. This call stores them and starts the avatar. The response is `session_id`.

Required headers:

- `Authorization: Bearer <YOUR_AKAPULU_API_KEY>`
- `Content-Type: application/json`

Required JSON fields:

- `avatar_id` — UUID of the avatar
- `show_ai_label` — boolean, whether the video shows **This is AI**
- `room_url` — `https://` URL of the Daily room, at most 2048 characters, with a room name
- `avatar_token` — meeting token the avatar joins with

```json
{
  "avatar_id": "66666666-7777-8888-9999-000000000000",
  "show_ai_label": true,
  "room_url": "https://example.daily.co/room-name",
  "avatar_token": "<avatar meeting token>"
}
```

```json
{
  "session_id": "11111111-2222-3333-4444-555555555555"
}
```

Pass `session_id` to `AkapuluAvatar`. Loading status is a server message on your bot with `type` `status`.

On failure the body includes `error` and `error_code`. See [Error responses](/api-reference/introduction#error-responses).
