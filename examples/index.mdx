The public example is [akapulu-examples](https://github.com/Akapulu/akapulu-examples).

It creates a private Daily room, mints the three meeting tokens, and calls `POST /api/live-sessions/`. The page joins with the browser token. The bot joins with its token, speaks first, and listens to the browser. Audio out and video out stay off. The avatar publishes the face and the played audio.

## Run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and set:

- `DAILY_API_KEY`
- `AKAPULU_API_KEY`
- `AKAPULU_AVATAR_ID`
- `AKAPULU_SHOW_AI_LABEL` as `true` or `false`
- `OPENAI_API_KEY`

`AKAPULU_API_URL` is optional. When it is unset, the example uses the production origin. A set value has to be an `http` or `https` origin.

```bash
python server.py
```

Open `http://127.0.0.1:7860` and choose Start call. The server handles one call at a time. A second start while a call is running returns an error.

The API key stays in that process. The page receives the Daily room URL and the browser token.

The room, the live-session body, and `AkapuluAvatar` are described in [Your bot](/guides/calls/your-bot).
