## Pipecat / Daily

The public example is [akapulu-examples](https://github.com/Akapulu/akapulu-examples) (repo root).

Deepgram Flux (`flux-general-multi`) hears the caller. OpenAI `gpt-5.4-mini` speaks, with reasoning off. Cartesia Sonic 3.6 speaks each finished sentence. It creates a private Daily room, mints the three meeting tokens, and calls `POST /api/live-sessions/`. The page joins with the browser token. Your voice bot joins with its token, speaks first, and listens to the browser. Leave audio out and video out off on your voice bot. It does not publish a camera or a microphone into the room. The avatar publishes the face and the played audio.

### Run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and set:

- `DAILY_API_KEY`
- `AKAPULU_API_KEY`
- `OPENAI_API_KEY`
- `DEEPGRAM_API_KEY`
- `CARTESIA_API_KEY`

The example uses Hollis, leaves **This is AI** off, and calls the Akapulu Labs production API.

```bash
python server.py
```

Open `http://127.0.0.1:7860` and choose Start call.

The API key stays in that process. The page receives the Daily room URL and the browser token.

The room, the live-session body, and `AkapuluAvatar` are described in [Pipecat](/guides/calls/pipecat). `create_akapulu_call` is the function that creates the room and the live session.

## LiveKit

The public browser example is [`akapulu-examples/livekit`](https://github.com/Akapulu/akapulu-examples/tree/main/livekit). Same repo as Pipecat/Daily, under `livekit/`.

It uses `create_akapulu_livekit_call` and `AvatarSession` from `livekit-akapulu`. LiveKit Inference runs Flux / GPT / Cartesia. The page joins with livekit-client on `http://127.0.0.1:7861`.

### Run

```bash
cd livekit
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and set:

- `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` (LiveKit Cloud project with Inference enabled)
- `AKAPULU_API_KEY`

```bash
python server.py
```

Open `http://127.0.0.1:7861` and choose Start Call.

Details: [LiveKit](/guides/calls/livekit). For Agent Console, see [`examples/console_agent`](https://github.com/Akapulu/livekit-akapulu/tree/main/examples/console_agent) in the package repo.
