Generated clip video can show an on-screen card so people watching can tell the media is AI-generated.

## Visible labels

On create, an on-screen card can be overlaid on the video:

- `show_ai_label` — **This is AI**
- `show_logo` — **Made by** plus the Akapulu Labs logo

Both default to `true`. `show_ai_label` can be `false` on any plan. `show_logo: false` needs [Starter](https://akapulu.com/pricing) or higher.

We recommend leaving `show_ai_label` as `true`. Some places, including the EU, have [rules about disclosing AI-generated media](https://digital-strategy.ec.europa.eu/en/faqs/transparency-obligations-under-article-50-ai-act).

How to set the flags is in [Workflow](/guides/clips/workflow#1-create-a-clip).

## Live conversations

Live avatar video can overlay the same **This is AI** card. It is off by default except on the public landing-page demo, which always shows it.

- [Connect](/api-reference/conversations/connect) accepts optional `show_ai_label` (Web SDK `@akapulu/server` `connectConversation` too). Allowed on every plan.
- [Hosted links](/guides/scenarios/hosted-links) store `show_ai_label` on the link. Visitors cannot override it.
- The Akapulu logo on live video is a Free-plan watermark, not a connect flag.
