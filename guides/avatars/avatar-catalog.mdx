The public catalog is a set of avatars you can use on a live call.

<Note>
A custom avatar is part of the [Enterprise plan]({{app-url}}/pricing).
</Note>

## Browse

Open [the catalog]({{app-url}}/catalog). Each row has an id, a name, a picture, a description, and a sample video.

<img src="/images/guides/avatars/use-public-avatar/catalog-avatar-demo.png" alt="Public avatar catalog showing name, profile image, description, and sample video" style={{ borderRadius: 12 }} />

## Use an id

Pass that UUID as `avatar_id`.

- On a [live session](/guides/calls/your-bot), it is the face that joins the room you created.
- On a [hosted link](/guides/calls/hosted-links), it is the face you pick in the dashboard.
